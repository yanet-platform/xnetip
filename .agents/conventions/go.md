# Go conventions

Loaded on demand by the agent writing or reviewing Go. This is the single source for these rules. Adapted from yanet2's Go conventions, minus everything that does not apply to a stdlib-only library (logging, gRPC, concurrency).

- **Receiver names**: always `m`. No type-letter mnemonics (`func (m IPv4Network) Contains(other IPv4Network) bool`).
- **No abbreviated identifiers**: spell out names in production and tests (`counters`, `windowOr`, `hostMask`, `intersected`). Only `ok`, `err`, `idx`, and short-scope type-assert temporaries are exceptions. Dense bit-twiddling may use the short mathematical names the Rust reference uses (`a1`, `m1`, `a2`, `m2`, `d`, `b`, `p`, `q`, `hi`, `lo`) **when a nearby comment defines them at first use**. No over-qualification either: `diff`, not `addrDiff`, unless another diff-like variable is in the same scope.
- **Naming**: constructors are `IPv4NetworkFrom`, `IPv4NetworkFromBits`, `IPv4NetworkFromPrefix`, `ParseIPv4Network`, `MustParseIPv4Network` — type-prefixed functions in the `net/netip` style, never bare `New`. Free functions over slices are verb-first with the family as suffix (`AggregateIPv4`, `BinarySplitIPv6`, `RangeToNetworksIPv4`). Prefix lengths are `int`, like `netip.Prefix.Bits()`.
- **Loop index**: use `idx`, not `i`, and prefer `for idx := range n` to C-style loops (Go 1.22+, enforced by `modernize`).
- **Maps**: `map[K]V{}` not `make(map[K]V)`.
- **Results**: "maybe" results are comma-ok `(T, bool)` (`Intersection`, `Merge`, `Prefix`, `ToIPv4Mapped`, `IPv4()`). `error` only for parsing and for constructors fed external data. Errors are built from the exported sentinels in `errors.go`, wrapped with `fmt.Errorf("xnetip.ParseIPv4Network(%q): %w", input, ErrX)` so `errors.Is` works and the input is echoed. Never `panic` in runtime code except `MustParse*`.
- **Value semantics**: all public types are small immutable value types (`IPv4Network` is 8 bytes, `IPv6Network` 32 bytes), methods take value receivers and never mutate. Slice functions (`AggregateIPv4`) mutate their input in place and return the kept prefix, like `slices.Compact`.
- **Bit math**: IPv4 on `uint32`, IPv6 on the unexported `uint128` (`hi`, `lo uint64`) — never on `[16]byte`. Use `math/bits` (`OnesCount64`, `LeadingZeros64`, `TrailingZeros64`, `Add64`, `Sub64`), no lookup tables.
- **Standard library only**, `unsafe` forbidden, cgo forbidden, reflection forbidden in runtime code. `net/netip` is the parser and the formatter in iteration 1 — delegate to it rather than hand-rolling.
- **Allocation-free runtime**: no `fmt.Sprintf` on hot paths, `AppendTo` builds strings into caller buffers, `String()` is `string(m.AppendTo(nil))` or a `netip` call. A new hot path gets a `testing.AllocsPerRun` test asserting `0`.
- **Function ordering**: top-down. Exported entry points first, each function's helpers directly below it, recursively (DFS pre-order over the call graph). Shared leaf helpers go under their first caller.
- **Comments**: follow `comments.md` — brief + blank + detailed, English, period-terminated, only where the code is not self-explanatory. No separator comments (`// ---- x ----`), no reasoning traces ("wait, actually…"), no restating the line below, no op-counts or compiler-behaviour claims in public docs. Correctness justifications (why a bit transform is legal) stay. `gofmt` does not wrap, so keep each line within ~80 columns by hand.
- **Doc comments**: every exported symbol has one, opening with its own name. Contracts that the Rust reference documents (normalization, host-index order, exact `Difference` count, `Compare` order being the sort key `Aggregate*` applies before its greedy pass, `Aggregate*` output order being deterministic but not sorted) are documented verbatim in spirit — they are API.
- **Call wrapping**: once a call spans multiple lines, the last argument gets a trailing comma and the closing paren stands alone.
- **Dead code is deleted**, never commented out or gated. Public API items stay once shipped.
- **Tests**: follow `tests.md` (naming `Test_<WhatToTest>_<Case>`, `// verifies that` brief, self-describing table-case `name:`), `package xnetip_test`, stdlib `testing` only with the helpers in `testutil_test.go`. Production comments never mention tests.
